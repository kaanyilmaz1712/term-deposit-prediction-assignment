# Bank Marketing - Term Deposit Prediction Assignment
Take Home Assignment

## Project Structure

main.ipynb - Model implementation and project description
report.pdf - Detailed explaination and solution to the assignments in German

## Installation

Install the required dependencies:

```bash
pip install numpy pandas matplotlib seaborn scikit-learn ucimlrepo jupyter
```

## Usage

Start Jupyter Notebook:

```bash
jupyter notebook
```

Open `main.ipynb` and run the cells sequentially.

The dataset is automatically retrieved from the UCI Machine Learning Repository using `ucimlrepo`.

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib & Seaborn
- Scikit-learn
